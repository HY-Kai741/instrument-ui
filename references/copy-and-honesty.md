# 文案与数据诚实

## 语气

界面是读数，不是宣传页。用名词化的判定式表达：

> 来源、依据、当前目标、数据状态、采集时间、下一步

一个句子只表达一个判断。不用感叹号连用。

## 硬规则

- 数字必须带口径或单位：`14,867 条（清洗后）`、`3 项必备技能未达标`、`耗时 1.2s`。
- 不给没有依据的百分比、匹配度、成功率。
- 不用营销词：赋能、一站式、领先、颠覆、极致、助力。
- 不用拟人化安慰：别担心、加油、你一定可以、相信你。
- 不用「智能」作为卖点形容词；要说明具体判断依据。
- 按钮用动词开头，≤6 字：`生成计划`、`提交成果`、`刷新岗位`。

## 对照

| 不要 | 改成 |
| --- | --- |
| 你的匹配度高达 92%！ | 9 项要求中命中 5 项，缺少 A/B 测试与 Tableau。 |
| 别担心，你一定可以的 | 当前证据不足：尚未提交 SQL 练习成果。 |
| 一站式赋能你的业务增长 | 采集 → 清洗 → 分析 → 复核 |
| 暂无数据 | 暂无记录：该来源未提供原始字段。 |
| 系统认为设备异常 | 压力 2.71MPa，超过阈值 2.60MPa，持续 4 分钟。 |
| 该门店表现很差 | 转化率 1.2%，低于同类门店中位数 2.8%。 |

## 数据诚实边界

适用于任何展示外部数据、评估结论或用户档案的界面：

1. 区分「演示 / 模拟数据」与「真实采集数据」，必须标注。
2. 区分「用户自述」与「系统验证」，自述不写成已验证。
3. 没有真实数据支撑时，不展示看似精确的百分比、匹配度、成功率。
4. 只有后端返回的判定结果才代表通过 / 失败；前端不得自行判定。
5. 后端未提供的遥测（Token、工具调用明细）显示「暂无记录」，不编造。
6. 证据不足只能写「证据不足」，不能推断「没有能力」或「不存在」。
7. 覆盖不等于掌握；采集到不等于已校验。
8. 系统字段（来源、数据状态、用户身份、时间戳）由后端覆盖，界面不提供修改入口。

领域示例（招聘场景）：岗位分「模拟岗位」与「公开招聘岗位」，模拟岗位不伪造链接；学生、测评、成长记录为演示数据；学历或课程覆盖不等于能力达标。

## 来源标注模板

```text
演示数据 · 非真实业务
外部采集 · {来源名} · {YYYY-MM-DD HH:mm}
以原始来源为准
```

列表页可以在行尾用紧凑形式，详情页必须展开为完整三行。
