# 迁移到别的项目

这套东西是**版式关系 + 材质层**，不是某个产品的页面模板。换个项目时，内容和数据全部换，下面这些关系保留。

## 先问四个问题

1. **主角是什么？** 一个核心结论（用主视觉大标题），还是一组实时读数（用读数条）？只能选一个。
2. **数据密度多高？** 超过 20 行、需要筛选和对比 → 台账 + 检索台；不到 10 条 → 用编辑式分区，不要硬做表格。
3. **有没有「可信度」问题？** 数据来自外部、可能延迟、可能缺失、可能未验证 → 必须有来源、时间、状态三元组。
4. **品牌色必须换吗？** 只有品牌规范强制时才换主色；换的时候只替换 `--accent` / `--accent-deep` / `--accent-soft` 三个值，其余不动。

## 保留什么

| 保留 | 原因 |
| --- | --- |
| 一处主视觉 + 其余台账 | 这是识别度的来源；去掉就变成普通后台 |
| 1px 发丝线分区 | 比卡片网格更接近「仪器」 |
| 等宽数字与编号 | 让读数可扫描、可比对 |
| 大写小号等宽标签 | 提供「刻度」感，且不抢正文 |
| 深色底 + 单一强调色 | 强调色一旦变多就失效 |
| 材质层（星轨 / 星云 / 光斑 / 渐入） | 静态截图之外的动态识别度 |
| 来源 / 时间 / 状态标注 | 数据产品的通用要求，不是本项目专属 |

## 可改什么

| 可改 | 说明 |
| --- | --- |
| 品牌名、导航项、文案 | 全部替换 |
| 数据模型与字段 | 岗位、设备、订单、实验都可以 |
| 主色的色相 | 保持「深底 + 单一高饱和强调」的关系即可 |
| 主视觉尺度 | 内容型产品可以降到 `clamp(40px, 5vw, 64px)` |
| 材质层数量 | 表单页、设置页、长文页可以只留星云和渐入，不要星轨 |
| 图表类型 | 折线、柱、热力都可以，颜色仍只用强调色 + 灰阶 |

## 三种典型映射

**实时监控台**
主视觉大标题 + 4 个读数 → 检索台 → 台账 + 设备详情。材质层全开。

**研究 / 分析工具**
主视觉换成一句结论（如「本月留存下降 3.2%」）→ 图表区 → 明细表。星轨可关，保留星云和渐入。

**内容 / 档案管理**
不要主视觉大标题；用 Page H1 30px + 台账。玻璃面板只用于详情抽屉，主区全用发丝线。

## 反例

- 把 Display 大标题塞进登录页、设置页、表单页。主视觉是「结论页」的语法，不是全局页头。
- 在一个页面里放两个 Display，或者 Display 下面再来一个 46px 的区块标题。
- 每张卡片都加玻璃和阴影，最后没有层级。
- 强调色用于装饰性图标、分割线、背景块。
- 数据没有来源和时间，却用精确到小数点的数字。
- 为了「高级感」加粒子、扫描线、故障风；这些不在本语言里。

## 验收顺序

1. 去掉所有颜色，只看灰阶：层级还成立吗？
2. 去掉所有动效：信息还完整吗？
3. 只看首屏：能说出这一页的主角和下一步吗？
4. 断网 / 无数据 / 数据过期：界面还诚实吗？
