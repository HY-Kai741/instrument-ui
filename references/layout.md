# 页面骨架

## 顶栏

```text
┌────────────────────────────────────────────────────────────────┐
│ 品牌标记 + 名称 │ 导航项 … │          成长助手 │ 身份 │ 登录   │
└────────────────────────────────────────────────────────────────┘
```

- 横向顶栏，`position: sticky`，`top: 0`，`min-height: 58px`。
- 背景 `--bg-panel`，下方 `1px solid rgba(255,255,255,.12)`。
- 左右内边距 `clamp(18px, 3vw, 44px)`，项间距 `2px`。
- 导航项：`12.5px`，常态 `rgba(255,255,255,.66)`；当前项纯白，文字下 1px 白线，左右各留 `11px`。
- 导航最多 9 项；超出横向滚动，滚动条隐藏，不折叠成「更多」。
- 右侧顺序固定：成长助手 → 身份 → 登录/退出。

## 状态带

顶栏下方一行，透明底、无边框、右对齐：

```text
演示身份 [ 张同学 ▾ ]     目标岗位 [ 数据分析师 ▾ ]
```

- 标签 `10px` 大写等宽，颜色 `--ink-dim`。
- 控件高 `34–38px`，圆角 `8px`（顶栏控件例外，可用 8px），底色 `rgba(18,25,32,.86)`。
- 不使用卡片底色，不与正文抢层级。

> 8px 圆角仅限顶栏控件。正文区仍遵守 0 / 3 / 6 / 10。

## 骨架 A：成长总览（编辑式）

```text
┌ 主视觉 min-height:350px ────────────────────────────────────┐
│  KICKER                                                     │
│  超大标题（clamp 58–104px）          ┌ 身份/目标卡 250–340px ┐│
│  一句话说明                           │ 当前目标 / 数据状态   ││
└──────────────────────────────────────┴──────────────────────┘
  读数 01 │ 读数 02 │ 读数 03 │ 读数 04      ← 竖线分隔
  01  区块标题                                右侧一句说明
  ────────────────────────────────────────────
  条目（横线分隔，无卡片）
```

- 主视觉：`min-height: 350px`，左右 padding `clamp(24px, 5vw, 68px)`，上下 `clamp(58px, 7vw, 92px)`。
- 主视觉使用 `--bg-panel`，其余页面用 `--bg-void`。
- 读数区 4 列，列间 `1px` 竖线；每列「编号 → 名称 → 读数 → 说明」。
- 区块用三位结构：等宽编号（01–05）+ H2 + 右侧说明；说明右对齐，最大 `300px`。
- 区块之间 `74px` 上下留白 + 1px 横线。
- 双栏区块比例 `1.38fr : 0.82fr`。
- 条目：`padding: 18px 0`，`border-top: 1px`，无背景、无圆角、无阴影。

## 骨架 B：检索控制台

```text
┌ 控制台（玻璃）──────────────────────────────────────────────┐
│  关键词输入                         命中 14,867 条            │
│  来源 / 城市 / 学历 / 经验 分面                              │
└──────────────────────────────────────────────────────────────┘
┌ 台账 1fr ───────────────────────────┐┌ 核对区 370px ─────────┐
│ 行 · 行 · 行                        ││ 岗位卡 / 依据 / 动作 │
│ 分页固定在底部                      ││                      │
└─────────────────────────────────────┘└──────────────────────┘
```

- 控制台在上，台账与核对区在下，`gap: 18px`。
- 控制台是玻璃面板；台账与核对区也是玻璃面板，同屏最多两层（控制台算一层）。
- 台账最小高度 `420px`；分页固定在台账底部，不随列表滚动。
- 核对区宽 `370px`，移动端转为整行。
- 不再使用「左筛选 + 中列表 + 右详情」的等高固定三栏。

## 骨架 C：台账 + 详情

```text
页面标题 30px
说明 13px
────────────────────────────────────────────────
列头（等宽 10px 大写，--ink-dim）
行 1
行 2
────────────────────────────────────────────────
```

- 用于证据、课程、任务等纯列表页，不需要玻璃面板。
- 列头不用背景色，只加底部 1px 线。
- 数值列右对齐并使用等宽字体。
- 行高由内容决定，最小 `44px`。

## 断点

新增代码只使用三档：

| 断点 | 变化 |
| --- | --- |
| `1180px` | 双栏收为单栏，读数 4 列变 2 列 |
| `900px` | 顶栏折叠为可横向滚动；检索页转单列；画布背景关闭 |
| `620px` | 字号降一档；按钮整行；表格转卡片式两行布局 |

规则：

- 移动端保留层级，不保留并排。
- 折叠后主操作仍在首屏，不被筛选器挤到第二屏。
- 表格在 `620px` 下转成「标题行 + 元信息行 + 动作行」，不做横向滚动。
