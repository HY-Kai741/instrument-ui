# 令牌与形态

所有值来自源项目 `app/webui/app.css` 的现行实现。新代码只使用这里的令牌，不新增裸色值。

| --- | --- | --- |
| `--bg-void` | `#080b0e` | 页面最底层 |
| `--bg-panel` | `#0b1015` | 顶栏、主视觉面板 |
| `--bg-glass` | `linear-gradient(160deg, rgba(9,23,30,.86), rgba(5,15,21,.82))` | 浮起的检索台、核对区 |
| `--surface-1` | `rgba(255,255,255,.02)` | 面板内浅底 |

| `--warn` | `#e4ba69` | 需注意、模拟数据 |
| `--danger` | `#d56d61` | 失败、不可用 |

### 规则

- `--accent` 单屏不超过三处。出现第四处时，改用 `--ink` 或线条表达。
- `--gold` 只标记目标岗位，一页最多一处；不与 `--accent` 同时用于同一元素。
- 数字和时间用 `--ink-dim` / `--ink-faint`，不用纯白。
- 背景允许一层径向渐变 + 一层画布（星轨 / 地球），必须在正文之下，且不影响对比度。
- 禁止：橙色文字、装饰性彩色图标、三色以上渐变、霓虹描边。

## 字体

```css
--sans: "IBM Plex Sans","Segoe UI","Microsoft YaHei","PingFang SC","Noto Sans SC",sans-serif;
--mono: "IBM Plex Mono","Cascadia Mono","SFMono-Regular",Consolas,monospace;
```

- 自托管，不引外链。字体文件在 `assets/fonts/`，SIL OFL 1.1。
- 数字、编号、时间、表格列一律 `--mono`，并开启等宽数字。
- 中文回退顺序固定，不插入其他西文字体。

## 字号阶梯

| 层级 | 字号 | 字重 | 字距 / 行高 | 用途 |
| --- | --- | --- | --- | --- |
| Display | `clamp(58px, 7.5vw, 104px)` | 600 | `-.03em` / `1.04` | 仅主视觉，一页一处 |
| Page H1 | `30px` | 600 | `-.04em` / `1.3` | 普通页标题 |
| Section H2 | `clamp(21px, 2.2vw, 28px)` | 600 | `-.025em` / `1.25` | 区块标题 |
| Sub H3 | `15–16px` | 600 | `-.01em` | 面板标题 |
| Body | `14px` | 400 | `1.6` | 正文 |
| Body Small | `12.5–13.5px` | 400 | `1.55–1.75` | 说明、表格 |
| Label | `10–11px` | 400–500 | 大写，`.08–.18em` | 编号、印章、标签 |

边界：

- 正文和表格不小于 `12px`。小于 `12px` 只允许等宽大写标签，不得用于成句文本。
- 中文字号低于 `12px` 时不再加字距，否则会散。
- 等宽大写标签每屏不超过 12 处。
- 中文 Display 行高 ≥ `1.0`、字距 ≥ `-.03em`；西文标题才可以用到 `-.05em` 或更低行高。

## 间距

基础序列：`4 / 8 / 12 / 18 / 26 / 38 / 74`。

- 区块上下留白：`74px`
- 面板内边距：`18–24px`
- 表格行内边距：`10–17px`
- 主内容左右：`clamp(22px, 4.5vw, 56px)`
- 内容最大宽度：`1240px`

## 圆角

| 值 | 用途 |
| --- | --- |
| `0` | 编辑式区块、顶栏控件、读数列 |
| `3px` | 输入框、小控件 |
| `6px` | 按钮、选中行 |
| `10px` | 玻璃面板 |

胶囊形（`999px`）只用于状态标签，不用于按钮和面板。

## 阴影

只用两种：

```css
--shadow-float: 0 18px 48px rgba(0,7,10,.2), inset 0 1px 0 rgba(255,255,255,.035);
--shadow-btn:   0 5px 16px rgba(0,0,0,.16);
```

- 静态区块不加阴影，用发丝线。
- 玻璃面板才用 `--shadow-float`。
- 不用彩色阴影做大面积发光；悬停时允许 `0 0 0 1px rgba(113,218,207,.12)` 的细描边。

## 动效

| 场景 | 时长 | 曲线 |
| --- | --- | --- |
| 悬停、按钮状态 | `150–180ms` | `ease` |
| 面板展开、抽屉 | `220–260ms` | `cubic-bezier(.2,.75,.25,1)` |
| 主视觉入场 | `600ms`（可延迟 `80ms`） | `cubic-bezier(.2,.75,.25,1)` |
| 路由切换 | `130ms` 出 / `180ms` 入 | `ease-out` |

- 悬停位移 ≤ `2px`。
- 按钮扫光单次 ≤ `600ms`，不循环。
- 背景漂移 ≥ `26s`，且必须能被 `prefers-reduced-motion` 关闭。
- `reduce` 下关闭：入场动画、位移、背景漂移、画布；保留颜色和边框变化。
